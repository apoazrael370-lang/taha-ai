طه AI — نسخة واجهة أولية
========================
المحتويات:
- index.html: واجهة عربية متجاوبة
- assets/background.jpg: الصورة التي اخترتها كخلفية
- manifest.json و sw.js: أساسيات PWA للتثبيت عند استضافتها عبر HTTPS

تشغيل سريع:
1) فك ضغط الملف.
2) افتح index.html في المتصفح لمعاينة الواجهة.
3) لكي تثبت كتطبيق PWA على أندرويد، ارفع المجلد إلى استضافة HTTPS ثم افتح الرابط في Chrome واختر "إضافة إلى الشاشة الرئيسية".

مهم:
هذه ليست APK، ولا تحتوي على محرك حقيقي لتوليد الفيديو. زر الإنشاء حاليًا يتحقق من النص ويعرض رسالة توضيحية. توليد الفيديو مجانًا بلا حدود ليس مضمونًا؛ يحتاج إلى دمج نموذج محلي متوافق أو خدمة استدلال مناسبة. لا توجد مفاتيح API أو اشتراكات مخفية في هذه النسخة.
